Document Architecture Specs

This layout viewer utilizes a responsive, frame-locked dual pane layout system.

1. Toggle the Notepad only via the upper toolbar button.

2. Pinch with two fingers anywhere on the workspace to zoom both PDF and Notepad simultaneously.

3. Drag the middle divider bar to compress and expand layout panes without overlapping UI elements.

Annotate on either surface using pen, highlighter, or straight connector tools.
